# Cambios de la versión 10

- Recuperación crítica de carga local: CSS y JavaScript se integraron directamente en `index.html`.
- La guía ya no depende de que Chrome encuentre `styles.css` o `app.js` mediante rutas relativas.
- La página inicial queda visible como respaldo incluso si JavaScript no se ejecuta.
- El ZIP se entrega sin una carpeta contenedora adicional: `index.html`, `assets/` y los demás archivos quedan directamente en la raíz.
- Se preservan las correcciones de la versión 9: precedentes con MA, encabezados de capturas sin duplicar, contacto alineado con el disclaimer y franja lateral de 576 px.
